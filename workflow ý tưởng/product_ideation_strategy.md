# Workflow: Product Ideation & Strategy

This workflow helps you define the high-level strategy and ideation for a new tech/AI product, based on the "Tech Start Up Guide" and "Step Up Product Guide" philosophies.

## Phase 1: Controlled Breakthrough Strategy (Đột phá có kiểm soát)
1. **Analyze the Market/Problem:**
   - Define the core problem you are trying to solve.
   - Run a competitive analysis using search tools to see what exists.
2. **Define the 'Controlled Breakthrough':**
   - Identify the one key area where the product will innovate (the "breakthrough").
   - Determine how the rest of the product will rely on proven patterns to minimize risk ("controlled").
3. **Risk Mitigation Plan:**
   - List extreme risks and how to avoid them (based on Tech Start Up Guide principles).

## Phase 2: Actionable Outcomes
- Draft a 1-page PRD (Product Requirement Document) outlining the core value proposition and the controlled breakthrough.
- (Optional) Use `generate_image` or UI tools to mock up a conceptual visualization.
