# Workflow: Architecture Design & Deployment with AI

This workflow acts as the "Một Đập Ăn Luôn" (One Hit Wonder) process, moving from AI Agent Architecture Vision to detailed IDE Execution.

## Phase 1: High-Level Architecture Vision
1. **System Context Diagram:**
   - Define the main actors, systems, and external APIs.
   - Suggest the tech stack (frontend, backend, database).
2. **Agent / AI Role Definition:**
   - If AI features are involved, define the prompts, context window management, and memory requirements.

## Phase 2: Detailed Execution Plan (IDE Level)
1. **Directory Structure & Data Models:**
   - Design the initial skeleton folder structure.
   - Define the database schema or JSON structures.
2. **Implementation Phasing:**
   - Break down the code implementation into atomic, testable PRs (Pull Requests) or tasks.
3. **Draft the Implementation Plan Artifact:**
   - Create `implementation_plan.md` in the current working directory to get user approval before writing code.
